> In 2010 Oracle picked "Plan B": ship Java 7 with what was ready, and move lambdas and modules to Java 8. That still meant almost five years between releases.

## @java-7

Java 7 was a collection of small language fixes, nicknamed Project Coin. Each one removes a bit of boilerplate, and try-with-resources alone prevents a whole class of leaked-file bugs.

## @java-8

Lambdas let you pass behaviour around as easily as data, and streams let you describe what to do with a collection instead of writing the loop. Java 8 changed how Java code looks more than any release since Java 5, and companies stayed on it for years.

> Java 9 arrived in September 2017, held up by the module system. Waits like that are why the next lesson's change to how Java ships matters.

## @java-9

Modules let a library say which of its packages others may use, and let the JDK itself be split into pieces. It was the hardest change in Java's history for existing code, which is why it slipped from Java 7, to 8, to 9.
